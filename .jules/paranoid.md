## 2026-08-09 - Domain Struct Missing String Redaction Guardrail
**Leak Pattern:** The domain struct `Credential` containing sensitive fields like `publicKey` and `externalID` was missing a custom `String()` method. While call-sites in `internal/application/auth.go` (`RegistrationResult`) manually redacted `PublicKey` during logging, any accidental `%+v` formatting of the raw `Credential` object itself would bypass these manual call-site redactions and leak key material.
**Learning:** Manual redaction at logging call-sites is brittle. If the domain struct itself doesn't implement a redacting `String()` method, the safety relies entirely on developers remembering to redact it every time they log it or wrap it.
**Prevention:** Implement a custom `String()` method on every domain struct containing cryptographic material (like `Credential`, `WrappedKey`, `RefreshToken`) that redacts sensitive fields by default. This provides a systemic guardrail that prevents leaks even if call-site redaction is forgotten.
